# Sales Data Analysis Report

## 1. Project Overview

### Project Title

Sales Data Analysis

### Project Description

This project analyzes a sales dataset using the Python pandas library.

The purpose of the project is to load real sales data, explore its structure,
clean the data, calculate important sales metrics, identify the best-selling
product, and generate a formatted analysis report.

### Objectives

The main objectives are:

- Load sales data from a CSV file.
- Explore the structure and contents of the dataset.
- Check and handle missing values.
- Detect and remove duplicate records.
- Calculate important sales statistics.
- Identify the best-selling product.
- Compare sales performance across regions.
- Generate a clear and readable analysis report.

---

# 2. Dataset Description

The dataset contains sales transaction information.

The columns are:

| Column     | Description                   |
|------------|-------------------------------|
| Date       | Date of the transaction       |
| Product    | Product sold                  |
| Quantity   | Number of units sold          |
| Price      | Price per unit                |
| Customer_ID | Unique customer identifier    |
| Region     | Sales region                  |
| Total_Sales | Total value of the transaction|

The dataset contains:

- 100 rows
- 7 columns
- 5 products
- 4 regions
